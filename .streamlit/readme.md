# Smart Vitamin Assessment Tool

An AI-powered personalized vitamin recommendation system for community pharmacies.

## Features
- Analyzes patient medications for drug-nutrient interactions
- Provides condition-specific nutrient recommendations
- Generates printable PDF reports for patients
- Integrates CPhA (Canadian Pharmacists Association) evidence guidelines

## Quick Start
1. Enter patient information
2. App analyzes medications, conditions, and lifestyle
3. Get personalized nutrient recommendations with evidence ratings
4. Export as PDF for patient

## Installation (for developers)
```bash
pip install -r requirements.txt
streamlit run vitamin_assessment_app.py
```
